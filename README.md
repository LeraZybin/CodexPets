# Rechka and Lumen — Pets for Codex

A static website with installation links and Pets v2 sprite sheets, ready for GitHub Pages.

## Publishing with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and the `assets` directory to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

After deployment, the installation buttons automatically use the site's GitHub Pages HTTPS address.
